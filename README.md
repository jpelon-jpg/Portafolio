# 🚀 Portafolio Personal – TU NOMBRE

Portafolio web personal basado en la plantilla **Resume de Start Bootstrap**, publicado en GitHub Pages.

🔗 **Demo en vivo:** https://TU-USUARIO.github.io/NOMBRE-REPO/

## Descripción del proyecto
- **Framework CSS:** Bootstrap 5 (incluido en la plantilla). No se usa Tailwind ni frameworks de JavaScript.
- **Plantilla:** Start Bootstrap – Resume v7.0.6
  - Descarga: https://startbootstrap.com/theme/resume
  - Repositorio: https://github.com/StartBootstrap/startbootstrap-resume (licencia MIT)

### Secciones del portafolio
| Sección | Descripción |
|---|---|
| Sobre mí | Presentación con nombre, datos de contacto, descripción personal y redes sociales. |
| Proyectos | Proyectos que he hecho o planeo hacer, con tecnologías y fecha. |
| Educación | Formación académica actual y anterior. |
| Skills | Íconos de lenguajes y herramientas, y lista de formas de trabajo. |
| Intereses | Pasatiempos e intereses personales. |
| Contacto | Metas de certificaciones y correo de contacto. |

## Estructura del repositorio
```
├── index.html
├── README.md
├── css/portafolio.css   (estilos de la plantilla, antes styles.css)
├── js/portafolio.js     (scripts de la plantilla, antes scripts.js)
└── img/                 (profile.jpg y capturas)
```

## Proceso de creación
1. Descargué la plantilla Resume desde Start Bootstrap y revisé sus archivos.
2. Creé el repositorio con la estructura `css`, `js` e `img`.
3. Renombré `styles.css` a `portafolio.css` y `scripts.js` a `portafolio.js`, y actualicé los enlaces en `index.html`.
4. Moví la foto de perfil a `img/profile.jpg` y la reemplacé por mi foto profesional real.
5. Cambié el contenido a español y a mis datos personales.
6. Cambié la sección "Experience" por "Proyectos", porque aún no tengo experiencia laboral; puse proyectos planeados.
7. En Skills quité los íconos de Angular y React (no uso frameworks JS) y agregué Git, Python y Bootstrap.
8. Cambié "Awards" por metas de certificaciones y contacto.
9. Probé el menú lateral y la vista en celular.
10. Subí todo a GitHub y activé GitHub Pages (Settings → Pages → rama `main`, carpeta `/root`).
